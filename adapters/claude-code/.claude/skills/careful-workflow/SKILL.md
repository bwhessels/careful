# Careful workflow

Read [portable policy](../../../core/policy.md). Resolve the project-declared specification authority before creating durable artifacts; use OpenSpec when declared and keep execution plans separate and linked. Classify the request, then apply the baseline controls. When its Deep distribution trigger applies, complete the [portable Deep change checklist](../../../core/deep-change-checklist.md) before implementation. For Deep work, create or use the declared authority and delegate `careful-independent-review` before handoff. After correcting a material finding, delegate a new independent review of the corrected artifact and apply the policy's clean-closure rule. If automatic skill activation is unverified or unavailable, say so and offer this skill explicitly.
