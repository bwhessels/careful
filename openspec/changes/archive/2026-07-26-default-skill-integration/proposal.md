## Why

Careful currently provides documentation and retrospective playbooks, but ordinary work can depend on the agent choosing to load those separate skills. The baseline checks must instead be part of the default workflow so users receive them without remembering commands.

## What Changes

- Make documentation-impact assessment and lightweight retrospective assessment explicit steps in `careful-workflow`.
- Retain specialist skills for dedicated documentation and full retrospective work.
- Provide tracked project guidance that activates Careful's default workflow when the plugin is installed.
- Add Careful's own self-hosting profile and an adopted-project fixture.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `default-skill-integration`: Make baseline documentation and retrospective checks intrinsic to the main workflow and define project activation guidance.

## Impact

Affected plugin skills, project guidance, self-hosting configuration, fixture documentation, and final handoff behavior.
